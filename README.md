# 背单词

中英双语词汇记忆 Android App。3920 个 CET4 / CET6 词汇，随机抽词速记 → 中译英 / 英译中测试 → 没记住的自动回到下一轮，直到全部拿下。

## 安装步骤

1. 手机浏览器打开上面的地址
   （**别在微信里直接点**，微信会拦 APK；万一打开了就点右上角「···」→「在浏览器中打开」）
2. 点「下载安装包 · 189 KB」
3. 下载完点开 `背单词.apk`
   提示「不允许安装未知来源应用」时 → 点「设置」→ 允许来自此来源 → 返回 → 再点一次
4. 桌面出现 **Aa** 图标的「背单词」，点开即用

安装包 189 KB · 支持 Android 5.0+ · 全程不需要联网 · 包名 `com.lang.easy`

## 功能

- **词库**：3920 词（CET4 2607 + CET6 1313），含中文释义、词性、美式音标
- **一轮流程**：随机 20 个新词速记 → 环节1 中译英 → 环节2 英译中，共 40 题
- **记忆判定**：每题提交后弹「记住了 / 没记住」，答对答错都弹
- **复习机制**：点「没记住」的词自动追加到下一轮的 20 个新词后面
- **完成条件**：所有词过完且无待复习词 → 「已完成所有单词背诵」
- **词汇表**：可搜索、按 CET4/CET6 分类、按 A–Z 筛选
- **进度**：存在手机本地，关掉再开还在

[qwerty-learner](https://github.com/Kaiyiwing/qwerty-learner) 的 CET4 / CET6 词典，合并去重后经清洗生成。
